# “AI 味”的表现与改写方法：首版调研

检索与核查日期：2026-10-26。主要语言：中文、英文。首版覆盖对话、项目文档、科研写作、代码和邮件；广告、小说、诗歌、法律文本、UI 文案等仅在分类表中给出延伸方向，尚无独立技能。

## 研究问题与方法

本项目从“模型反复使用‘不是 X，而是 Y’”这一用户观察出发，检索语言特征、文体差异、邮件语用、迎合行为、代码质量与检测偏差研究。检索词包括 `linguistic characteristics AI-generated text`、`human AI writing domains`、`Chinese Weibo stylometric features`、`AI refusal emails`、`sycophancy language models`、`AI generated code maintainability`。

优先采用论文原始页面、作者摘要与可访问的正文。表中逐项注明阅读深度；摘要级核查仅用于摘要明确支持的结论。未下载并重分析数据，也未复现这些论文。本文是面向技能设计的范围性调研，未进行系统综述所需的完整数据库检索、预注册筛选或偏倚评价。“所有 AI 味”无法形成封闭清单：模型、语言、任务、读者预期和提示都会改变表现。

将依据分成三类：

- **研究观察**：特定数据与模型中测得或由参与者报告的现象，标明来源和适用范围。
- **编辑/工程建议**：由任务目标推导的可操作方法，仍需在具体材料中判断。
- **个人偏好**：例如少用无必要的对照句。可以尊重，不推广为语言的普遍缺陷。

## 哪些表现值得检查

S1、S2、S3、S4 支持跨层次观察：词汇偏好、句法与语义组织、正式程度及结构重复。S9 提供中文短评论的有限补充。它们共同支持“按场景检查”的方向，但没有建立一套跨语言、跨模型通用标记。

“不是 X，而是 Y”在本项目中属于用户观察和编辑偏好。没有在此次核查中找到足以证明该中文句式是通用模型指纹的证据。它让人不适，可能因为反复出现、凭空制造对立、替读者纠正未持有的观点，或者把简单事实包装成顿悟。这是对具体文本的编辑分析。

相同句式也能做必要的事：“401 表示认证失败，不代表服务器崩溃。”这里的区别直接回答问题，删除后会损失信息。因此处理单位应当是句子的作用与上下文。

词汇层之外，内容可能没有具体事实、反复重新表述标题、把每个话题凑成三点、用宏大意义收尾，或对所有用户观点先夸奖。这些是首版编辑检查项，其来源详见 [分类表](patterns.md)，不作作者身份判断。

## 为什么分成五个技能

| 场景 | 表达要完成的工作 | 最容易被“润色”损坏的内容 |
| --- | --- | --- |
| 对话 | 回答问题、交换判断、承接情绪 | 问题焦点、真实分歧、情境与亲疏 |
| 文档 | 让读者成功操作并理解能力范围 | 命令、版本、路径、验证状态 |
| 科研 | 把主张绑定到证据 | 数值、引用、比较条件、因果与不确定性 |
| 代码 | 在项目中实现可维护的行为 | API、失败语义、边界条件、本地约定 |
| 邮件 | 在关系中协调行动 | 礼貌功能、责任、时间、承诺与拒绝 |

S5 对邮件、S7 对代码、S6 对对话分别提供不同层面的证据。README 的操作组织、科研证据核对和具体代码重构规程则主要属于编辑与工程建议。把这些质量目标拆开，能减少同一套“更口语、更短”指令造成的误改。

## 改写方法

1. 明确读者、任务、渠道和作者希望保留的语气。材料足够就直接做，关键事实缺失才询问。
2. 先标记不可随意更改的信息：事实、引用、数值、命令、约束、承诺、错误语义。
3. 找出有阅读后果的问题，说明哪句重复、空泛、误导或不合关系。不要仅凭一个词触发替换。
4. 从已有材料补具体对象、依据与行动；删去无信息增量的修辞。事实缺口留给作者核实。
5. 对照原稿复核含义和场景功能，再检查读起来是否自然。

这套流程是项目提出的编辑方案，尚无对照实验验证其整体效果。技能内包含有限、清晰的操作规则；详细案例放入各技能目录，便于单独安装。

## 怎么评估

按事实保真、任务完成度、具体性、场景适配和重复负担审阅，详见 [评估规程](../evals/README.md)。正例之外必须保留反例：必要否定、学术术语、正式问候、输入校验与真实对照。

“变短”“没有某个词”“检测器认为像人”都不足以证明改写成功。S8 说明至少一些检测器存在群体偏差；本项目采用可核对的内容质量指标，并计划积累匿名化实际使用反馈。

## 局限与后续

首版主要依据 2023—2025 年论文及其后续版本，研究页面在 2026-10-26 检索。样本和模型较旧的结论需要谨慎用于新模型；中文长文、技术文档与多语邮件证据尤其有限。

目前的案例均为构造示例，不能证明真实任务中的改善幅度。下一步应收集获得授权的真实前后稿，按领域盲评并记录语义回归。广告、文学、教学和产品文案可据此决定是否新增技能，避免先用通用规则覆盖所有领域。
