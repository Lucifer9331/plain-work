# 文档示例

以下均为构造示例。

已知：仅验证了一个推理样例，完整评测未运行。

原句：“本项目提供了完整、可靠的论文复现方案，助力研究者轻松探索前沿技术。”

修改：“本项目实现论文中的推理流程，已验证一个样例。完整评测尚未运行。”

原句：“我们关注的不是简单运行，而是建立可复现闭环。”

如果没有记录，删去宏大承诺；有记录时，写具体入口、参数、数据版本和检查方式。缺少参数时向作者标注缺口，避免补造。

原句：“运行脚本即可获得令人满意的结果。”

需要补充可核实的命令、输入和输出位置。未知输出路径时写“输出位置待核实”，或将疑问放进编辑备注，不能编造 `results/`。

需要保留：“当前仅支持 CPU 推理，不支持 GPU。”这是用户选择环境的依据。

英文：“A powerful, seamless, end-to-end solution for modern workflows.”

已有事实为 CSV 转 JSON 时：“Convert CSV files to JSON.” 若还存在大小、编码或格式限制，应保留。
